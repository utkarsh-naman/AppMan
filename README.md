# AppMan

AppMan is an Android app-management UI built around a directly embedded ADB client. It does **not** use Shizuku.

## Wireless debugging
- Android 11+ is required for the native pairing flow.
- AppMan cannot turn Developer options or Wireless debugging on programmatically; Android deliberately keeps those controls user-mediated.
- AppMan discovers the pairing service over mDNS, accepts the six-digit code through the app or its persistent notification, pairs using the Android wireless-debugging protocol, then reconnects over the TLS ADB service.
- The Android pairing code is generated by the OS and is not controllable or permanently fixed by an app. The persistent notification is for entering the current code, not for changing how Android generates it.

## Build
Open this directory in Android Studio (JDK 17+ recommended) and sync Gradle. The project uses `libadb-android` for the ADB protocol implementation.

## Safety
The terminal intentionally executes commands as the ADB shell user. Destructive actions are gated in the UI and every action is echoed to HOOD. Unsupported OEM-specific network commands are reported rather than silently treated as successful.
